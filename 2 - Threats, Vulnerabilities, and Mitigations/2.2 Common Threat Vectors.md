#### Threat Vector
- A method used by the attacker to gain access to the target
- IT security professionals spend their career watching these vectors

#### Message-based vectors
- One of the biggest and most successfully threat vectors
- Email w/ malicious links, downloads
- SMS (Short Message Service)
- Phishing attack (click a link)
	- Deliver the malware to the user
- Social engineering attacks
	- Invoice scams, crypto scams

#### Image-based vectors
- **SVG** image format
	- The image is described in XML
	- Significant security concerns, HTML injection, Javascript attack code.
	- Browsers must provide input validations

#### File-based vectors
- More than just .exe files
- Adobe PDF
	- File format containing other objects
- Compressed files w/ many diff files inside
- Microsoft Office
	- Documents w/ macros, add-in files

#### Voice call vectors
- Vishing
	- Phishing over the phone
	- DO NOT REDEEMMM (classic)
- Spam over IP (large scale phone calls)
- War dialing
	- Attackers trying to find unpublished phone numbers that they can use to gain access to systems
- Call tampering

#### Removable device vectors
- Get around the firewall with USB
- Software on USB flash drives
	- Infect air gapped networks
- Throw some USB drives on the ground of a company parking lot
- Data exfiltration with little effort & no bandwidth

#### Vulnerable software vectors
- Client-based
	- Infected .exe
	- Known/unknown vulnerabilities
	- We need security updates
- Agentless
	- No installed .exe
	- Compromised software on servers would affect all users
	- Client runs a new instance each time

#### Unsupported systems vectors
- Unsupported systems aren't patched, maybe with no option to
- Outdated operations systems
- Single system could be an entry
	- Keep an inventory of all systems in the org.

#### Unsecure network vectors
- Wireless
	- Outdated security protocols
	- Open/rogue wireless networks
- Wired
	- Unsecure interfaces (need 802.1X)
- Bluetooth
	- Reconnaissance into an org
	- Implementation vulnerabilities

#### Open service ports
- Network based services connect via UDP or TCP port
- Every open port is an opportunity for attacker
	- App misconfiguration / vulnerability
- More services = more open ports = maybe less secure
- Firewall rules

#### Default credentials
- Change your password...

#### Supply chain vectors
- Tamper with underlying infrastructure or manufacturing process
- Managed service providers (MSPs)
	- Access many diff customer networks from one location
	- Perfect place for an attacker. Attacker to MSP = access to systems.
		- Target in 2013 had malware on all POS systems thru this.
- Suppliers
	- Fake Cisco switches
	- Counterfeit networking equipment

## Phishing
- Social engineering with a touch of spoofing
- Often delivered by email, text, etc.
- Check the URL / website graphics

#### Business email compromise
- We trust email sources, especially in work email addresses
- Spoofed email addresses
	- Very close to email of company
- Financial fraud. Send emails with updated bank info, find logins. Use reset password feature 

#### Tricks 
- Typo-squatting
	- A type of URL hijacking, e.g. a replaced letter
- Pretexting
	- Lying to get info
	- Attacker is a character
- Vishing (voice phishing)
- Smishing (sms phishing)

___
## Impersonation
#### The pretext
- Before the attack, the trap is set with an actor & story
-  "Hello, this is __ from _ company, there are some problems with _ and we need your info."
#### Impersonation
- Attacker is pretending to be some they aren't
- Use some details from reconnaissance to convince you
- Attack the victim as someone higher in rank
- Throw tons of technical stuff around so you trust them

#### Eliciting Info
- Extracting info from the victim
- Often seen with vishing
- Well-documented psychological techniques, not just "what's your password"

#### Identity fraud
- Identity can be used by others
- Credit card fraud
	- Open card in your account or use your credit card info
- Bank fraud
	- Attacker gains access to your account or opens a new one
- Loan fraud
	- Once bank fraud, they can get a loan
- Govt. benefits fraud
	- Attacker sends in your tax forms as you, they get your tax refund

## Watering Hole Attacks
- The attackers can't get into a secure system
- They will want the system to come to them
#### The execution
- Determine which website the victim group uses
	- Local coffee / sandwich shop
- Infect one of these third-party sites
- Infect all visitors to the sites
	- But attacker only looks at specific visitors because they have the money

#### Watching the watering hole
- Defense-in-depth
	- Multiple layers of security
- Firewalls and IPS
	- Firewall might allow traffic through, IPS will see the contents and block it
- Anti-virus / anti-malware signature updates
___
## Other Social Engineering Attacks
#### Misinformation
- Disseminate factually incorrect info to create confusion and division
- Influence campaigns
	- Sway public opinion on political/social issues
- Nation-state actors use this
- Advertising
- Enabled through social media

#### The misinformation process
- Create fake users -> create content -> post on social media -> amplify message -> real users share message -> mass media picks up the story

#### Brand impersonation
- Pretend to be a well-known brand
- Create thousands of impersonated sites
	- Get into the google index to show up on google search
- Malware infection is almost guaranteed
