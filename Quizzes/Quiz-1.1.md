# Quiz 1.1 — Security Controls
*Professor Messer SY0-701 · Section 1.1*

---

### 1. Firewalls and anti-virus software are examples of which control category?
- [ ] Managerial
- [ ] Operational
- [ ] Technical
- [ ] Physical

<details>
<summary>Show Answer</summary>
<p><strong>Answer:</strong> Technical</p>
<p>Technical controls are implemented using systems, such as operating systems, firewalls, and anti-virus software.</p>
</details>

---

### 2. Security policies and standard operating procedures fall under which control category?
- [ ] Managerial
- [ ] Technical
- [ ] Physical
- [ ] Compensating

<details>
<summary>Show Answer</summary>
<p><strong>Answer:</strong> Managerial</p>
<p>Managerial controls are administrative controls associated with security design and implementation, such as policies and SOPs.</p>
</details>

---

### 3. Which control category is implemented by people rather than systems, such as security guards and awareness programs?
- [ ] Technical
- [ ] Physical
- [ ] Operational
- [ ] Directive

<details>
<summary>Show Answer</summary>
<p><strong>Answer:</strong> Operational</p>
<p>Operational controls are controls implemented by people instead of systems, e.g. security guards and awareness programs.</p>
</details>

---

### 4. Fences, locks, badge readers, and TSA checks are examples of which control category?
- [ ] Physical
- [ ] Technical
- [ ] Managerial
- [ ] Operational

<details>
<summary>Show Answer</summary>
<p><strong>Answer:</strong> Physical</p>
<p>Physical controls limit physical access using things like fences, locks, badge readers, and TSA checks.</p>
</details>

---

### 5. A control that blocks access to a resource, digitally or physically, is called what type of control?
- [ ] Deterrent
- [ ] Corrective
- [ ] Preventive
- [ ] Compensating

<details>
<summary>Show Answer</summary>
<p><strong>Answer:</strong> Preventive</p>
<p>Preventive controls block access to a resource, and can be either digital or physical.</p>
</details>

---

### 6. A splash screen or warning sign that discourages an intrusion attempt is an example of which control type?
- [ ] Deterrent
- [ ] Detective
- [ ] Directive
- [ ] Corrective

<details>
<summary>Show Answer</summary>
<p><strong>Answer:</strong> Deterrent</p>
<p>Deterrent controls discourage an intrusion attempt without necessarily blocking it outright.</p>
</details>

---

### 7. System logs and motion detectors are examples of which control type?
- [ ] Preventive
- [ ] Detective
- [ ] Compensating
- [ ] Directive

<details>
<summary>Show Answer</summary>
<p><strong>Answer:</strong> Detective</p>
<p>Detective controls identify and log an intrusion attempt, such as system logs or motion detectors.</p>
</details>

---

### 8. Which control type is applied after a detected event to reverse its impact, such as backup recovery?
- [ ] Corrective
- [ ] Deterrent
- [ ] Preventive
- [ ] Compensating

<details>
<summary>Show Answer</summary>
<p><strong>Answer:</strong> Corrective</p>
<p>Corrective controls are applied after a detected event to reverse its impact, e.g. backup recovery.</p>
</details>

---

### 9. Requiring multiple security staff when an existing control isn't sufficient is an example of which control type?
- [ ] Directive
- [ ] Compensating
- [ ] Detective
- [ ] Preventive

<details>
<summary>Show Answer</summary>
<p><strong>Answer:</strong> Compensating</p>
<p>Compensating controls use other means to provide protection when existing controls aren't sufficient, and can be temporary.</p>
</details>

---

### 10. A weak control that simply directs a subject towards security compliance (like a policy telling employees what to do) is called what?
- [ ] Deterrent
- [ ] Corrective
- [ ] Directive
- [ ] Compensating

<details>
<summary>Show Answer</summary>
<p><strong>Answer:</strong> Directive</p>
<p>Directive controls direct a subject towards security compliance but are considered a relatively weak control on their own.</p>
</details>
