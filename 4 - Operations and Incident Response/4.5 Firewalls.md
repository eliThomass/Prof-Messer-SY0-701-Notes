#### Network-based firewalls
- Filter traffic by port number or application
	- Traditional vs NGFW
- Encrypt traffic
	- VPN between sites
- Most firewalls can be layer 3 devices
	- Often sits on the ingress/egress of the network
	- Provides NAT and dynamic routing
#### Next-generation Firewalls (NGFW)
- The OSI application layer
	- Layer 7 (app) firewall
- Can be called diff names
	- App layer gateway
	- Deep packet inspection device
	- Stateful multilayer inspection device
- Requires some advanced decodes
	- Every packet must be analyzed, categorized, and a decision determined
#### Ports and protocols
- Make forwarding decisions based on protocol and port number
	- Add to NGFW for additional security policy options
	- Traditional port-based firewalls do this
- Based on both protocol and port e.g. tcp/443 (https), or udp/53 (DNS)
#### Firewall rules
- A logical path
	- Usually top-to-bottom
- Usually more specific rules are at the top, then more generic rules are lower down in the rulelist
- Implicit deny
	- Include a deny at the bottom if no rules match traffic
- **Access control list (ACL)**
	- Allow or disallow traffic
	- Grouping of categories, source ip, dest ip, port number, policy, more

#### Screened subnet
- An additional layer of security between you and the Internet
- Commonly holds services/devices that need to be accessed by the Internet
	- Prevents any from the Internet from accessing the internal network
	- Traffic is redirected to this screened subnet
#### IPS rules
- Intrusion Prevention System usually integrated into a NGFW
- Different ways to find malicious traffic such as looking at it as it passes by
- Signature-based
	- Look for a perfect match of a software signature
- Anomaly-based
	- Build a baseline of what's normal.
	- Unusual traffic patterns are flagged
- You determine what happens when unwanted traffic appears (block, allow, send an alert, etc.)
- Usually IPS has thousands of signatures inside
- Rules can be customized by group
