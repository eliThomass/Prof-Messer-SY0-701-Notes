- The attackers never sleep
- Monitor all entry points
	- Logins, publicly available services, data storage locations, remote access
- React to security events
	- Account access, firewall rule base, additional scanning
- Status dashboards
	- Get the status of all systems at a glance
#### Monitoring Computing Resources
- Systems
	- Authentication - logins from strange places
	- Server monitoring - Service activity, backups, software versions
- Applications
	- Availability - uptime / response times
	- Data transfers - increases or decreases could indicate data exfiltration
	- Security notifications
- Infrastructure
	- Remote access systems - employees, vendors, guests
	- Firewall and IPS reports - increase or type of attack
#### Log aggregation
- **SIEM (Security Info and Event Manager)**
	- Consolidate many diff logs to a central database
	- Servers, firewalls, VPN concentrators, SANs, cloud services
- Centralized reporting
- Correlation between diverse systems
	- View auth and access
	- Track app access
	- Measure and report on data transfers
#### Scanning
- A constantly changing threat landscape
- Actively check systems and devices
	- OS types and versions
	- Device driver versions
	- Installed apps
	- Potential anomalies
- Gather the raw details for information
#### Reporting
- Analyze the collected data
- Status information
	- Number of devices not up to date/in compliance
	- Devices running older OS versions
- Determine best next steps
- Ad hoc info summaries
#### Archiving
- It takes an average of 9 months for a company to identify and contain a breach
- Access to data is critical
	- Archive over an extended period for extra backups
- May have a mandate to do this
	- State/Fed law or organization requirements
#### Alerting
- Real-time notification of security events
	- Increase in authentication errors
	- Large file transfers
- Actionable data
	- Keep the right people informed
	- Enables quick response and status info
- Notification methods
	- SMS/text
	- Email
	- Security console
#### Alert response and remediation
- Quarantine system
	- Prevent a security issue from spreading
	- Foundational security response
- Alert tuning
	- A balancing act
	- Prevent false positives and false negatives

## Security Tools
#### Security Content Automation Protocol (SCAP)
- Many diff security tools on the market
	- NGFWs, IPS, vulnerability scanners, etc.
	- They all have their own way of evaulting a threat.
	- How to fix? Use SCAP to consolidate duplicate vulnerability reports
- Allows tools to identify and act on the same criteria
	- Validate security config
	- Confirm patch installs
	- Scan for a security breach
- These different tools can now work together in a shared language
#### Using SCAP
- SCAP content can be shared between tools
- Especially useful in large enviornments
	- Many diff OS and apps
- This specification standard enables automation
	- Even between different tools
- Automation types
	- Ongoing monitoring
	- Notification and testing
	- Remediation of noncompliant systems
		- All automatically!!
#### Benchmarks
- Apply security best-practices to everything
	- OS', cloud providers, mobile devices, etc.
	- The bare minimum security settings
- Mobile device examples: disable screenshots, disable recordings, prevent voice calls when locked, force encryption backups, etc.
#### Agents/agentless
- Check to see if the device is in compliance
	- Install a software agent onto the device or...
	- Run an on-demand agentless check
- Agents can usually provide more detail
	- Always monitoring for real-time notifs on compliance
	- Must be maintained / updated
- Agentless runs without a formal install
	- Does not require ongoing updates to an agent
	- Will not inform or alert if not running
#### SIEM
- Security Information and Event Manager
- Log collection of security alerts
- Log aggregation and long-term storage
- Reporting engine
- Data correlation
- Forensic analysis
#### Anti-virus and anti-malware
- Anti-virus is the popular term
	- Trojans, worms, macro viruses
- Malware refers to the broad malicious software category
- Terms are effectively the same these days
#### Data Loss Prevention (DLP)
- Where's your data?
	- SSN, credit card numbers, medical records
- Stop the data before the attacker gets it
- Monitor traffic in real-time and block it is sensitive data is contained
- So many sources, so many destinations
	- Often requirements multiple solutions
#### SNMP
- Simple Network Management Protocol
	- A database of data **(MIB)** - Management Information Base
	- The database contains **OIDS** - Object Identifiers
	- Polls devices over udp/161, they respond with how much data they have sent in a period
- Requests stats from a device
	- server, firewall, workstatoin, swtich, routers
- Polls devices at fixed internals
	- This caa create graphs based on how many bytes a device sent with the fixed internal periods.
#### SNMP traps
- Most SNMP operations expect a poll
- SNMP traps can be configured on the monitored device
	- Communicates over udp/162 when the trap fires
- Set a threshold for alerts
	- If the number of CRC errors increases by 5, send a trap
	- Monitoring station can react immediately
#### NetFlow
- Gather traffic statistics from all traffic flows
	- Shared communication between devices
- **NetFlow**
	- Standard collection method
	- Many products and options
- Probe and collector
	- Probe watches network communication
	- Summary records are sent to the collector
- Usually a separate reporting app linked to the collector
	- See top 10 conservations on network between devices, etc. 
#### Vulnerability Scanners
- Usually minimal invasive
	- Unlike a pentest
- Will gather details about if a system may have a vulnerability
- Port scan
- Identify systems and security devices
- Test from outside/inside
