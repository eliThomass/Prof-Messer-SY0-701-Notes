#### Automation benefits
- Save time, no typing required
- Enforce baselines
	- Missing an important security patch
	- Automatically install when identified
- Standard infrastructure configurations
	- Use a script to build a default router configuration
	- Add firewall rules to a new security appliance
	- IP configs, security rules, and standard config options
- Secure scaling
	- Orchestrate cloud resources with automation to ensure proper security also scales
- Employee retention
	- Automate the boring stuff
	- Ease the workload
	- More rewarding work
- Reaction time
	- Computer is much faster than us, events can be addressed immediately
- Workforce multiplier
	- Allows the smart people to do work somewhere else (or be laid off...
#### Cases for automation
- User and resource provisioning can be automatic to
	- File and resource access. Privileges too
- Guard rails
	- A set of automated validations
	- Limit behaviors and responses people input
	- Reduce errors and constantly check to ensure proper implementation
- Security groups
	- Assign or remove group access
	- Constant audits without human intervention
- Ticket creation
	- Automatically identify issues
	- Script email submissions into a ticket
- Escalation
	- Correct issues before involving a human
	- If issues isn't resolved, contact the on-call tech
- Controlling services and access
	- Automatically enable/disable services
	- No set and forget, like humans do
- Continuous integration and testing
- Integrations and APIs
	- Interact with third-party devices and services
	- Cloud services, firewalls, OS'
#### Scripting considerations
- *Complexity* with many moving parts, all working together
- *Cost*
	- It takes money to create the script and implement it
- *Single point of failure* if it stops working
- Technical debt
	- Patching problems may push the issue own the road
	- It'll be more expensive to fix later
- Ongoing supportability
	- Script works great now, but might not later...
