This repository is a log of the notes I will be taking while going through Professor Messer's YouTube course for the SY0-701 Security+ Exam. 

The Security+ exam consists of a maximum of 90 questions that must be answered within 90 minutes. The exam questions are MCQ, single answer, performance-based, along with others like matching / sorting. To pass, a score of at least 750 on the 100-900 scale must be achieved. 

There are five domains to the exam, listed below. The notes in this repo are organized between these five domains.

|                    Domain                     | % of Exam |
| :-------------------------------------------: | :---------: |
|         1 - General Security Concepts         | 12%       |
| 2 - Threats, Vulnerabilities, and Mitigations | 22%       |
|           3 - Security Architecture           | 18%       |
|            4 - Security Operations            | 28%       |
| 5 - Security Program Management and Oversight | 20%       |
|                    *Total*                    | 100%      |
I will be updating it as I progress through the videos.
